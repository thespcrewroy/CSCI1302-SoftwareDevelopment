## B+ Tree Insertion

# YouTube Example:
Q) Insert into the B+ Tree of *order 5* following: `12, 5, 20, 8, 3, 30, 15, 7, 35, 31, 6, 1, 55, 52`

* Order = 5
  * Each Node Max Children = 5
  * Each Node Min Children = ceil(5/2) = 3
  * Max Key = 5 - 1 = 4
  * Min Key = 3 - 1 = 2
* Root Exceptions
  * Min Children = 2
  * Min Key = 1
  
`#1 [- - - -]`

`#1 [3 5 8 12 20]`

B+ #1 Tree Overflow. Median = 8.

```
#1 [#2 8 #3 - - -]
#2 [3 5 - -]
#3 [8 12 20 -]
```

#3 [8 12 15 20 30]
