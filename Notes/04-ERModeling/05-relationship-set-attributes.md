# Relationship Set Attributes

## Core Idea

<p align="center">
  <img src="https://github.com/thespcrewroy/CSCI-4370/blob/main/Notes/assets/relationshipsetattributeexample.png" alt="Relationship Set Attribute Example" width="800" />

* Relationship tables normally have just foreign key constraintted attributes that connect one to many entities
* However, a relationship set with a relationship set attribute(s) are attributes of the relationship set itself, with no foreign ties
* The advisement start date here is not an attribute of an entity (instructor or student).
* The advisement start date is rather an attribute of the relationship set (advisor).
