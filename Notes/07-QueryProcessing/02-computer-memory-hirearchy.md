> There are tradeoffs for using different memory types

## Primary Storage (On-CPU)
* **Registers:** smallest and fastest memory used for immediate calculations.
* **Cache:** stores frequently used data, being closer to the CPU than RAM.

## Primary Storage (Off-CPU)
* **Main Memory (RAM):** stores currently running programs.

## Block Storage
* **Flash Disk (SSD):** permanent storage that is a faster alternative to hard disk.
* **Traditional Disk (HDD):** long-term large data storage.

## Hirearchy
* Going Up
  * Faster
  * More expensive monetarily
  * Smaller size
* Going Down
  * Slower
  * Cheaper
  * Larger size
  * More permanent storage
